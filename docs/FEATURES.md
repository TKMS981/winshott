# Feature inventory

状態: Phase 1 foundation実装後。撮影・OCR・QRなどの画像処理機能は未実装で、UIにもその状態を表示する。

| 機能 | 優先 | 予定Phase | 完了条件 |
|---|---:|---:|---|
| 範囲選択撮影 | 最重要 | 2 | オーバーレイ、ドラッグ、移動/リサイズ、寸法表示、Escape取消、Enter確定、ピクセル精度、DPI/Retina/複数画面で撮影できる |
| 全画面撮影 | 最重要 | 2 | 現在画面と全画面を選べ、プレビュー/コピー/保存できる |
| ウィンドウ撮影 | 最重要 | 2 | 取得可能なウィンドウ一覧から撮影し、失敗理由を示す |
| クリップボード | 最重要 | 2 | 画像・文字列のコピーと読み出しを実機確認 |
| ファイル保存 | 最重要 | 2 | PNG/JPEG保存、読み込み、保存先の決定を確認 |
| スクロール撮影 | 最重要 | 3 | 手動/自動、重複位置の検出、結合、補正、プレビュー、上限、一時停止/再開/取消 |
| OCR | 最重要 | 4 | 日本語/英語、範囲OCR、座標付き結果、対応言語一覧、コピー |
| QR/バーコード | 最重要 | 4 | 画像/範囲から複数検出し、文字列/種類/位置/状態を表示・コピー。URLを自動起動しない |
| 図形注釈 | 追加 | 5 | 矢印、四角、円を個別レイヤーで追加/編集できる |
| テキスト/フリーハンド | 追加 | 5 | テキスト配置とペン入力を編集できる |
| モザイク/ぼかし | 追加 | 5 | 指定範囲へ適用し、元画像を保った編集と書き出しができる |
| トリミング/リサイズ | 追加 | 5 | Undo/Redo可能な編集として適用できる |
| Undo/Redo | 追加 | 5 | 編集コマンドを安全に戻す/やり直す |
| カラーピッカー | 追加 | 6 | 画素色を選択し、値を表示/コピーできる |
| Pin | 追加 | 6 | 撮影画像を最前面ウィンドウとして表示できる |
| 遅延撮影 | 追加 | 6 | 秒数を指定し、撮影前にキャンセルできる |
| 履歴 | 追加 | 6 | ローカル履歴を閲覧し、再表示/コピー/保存できる |
| ホットキー | 追加 | 6/7 | 範囲 Ctrl+Shift+A、全画面 Ctrl+Shift+1、ウィンドウ Ctrl+Shift+W、スクロール Ctrl+Shift+S、OCR Ctrl+Shift+O、QR Ctrl+Shift+Qを初期候補とし、macOSはCommand系に置換。設定変更と競合通知に対応 |
| 設定 | 追加 | 1/6 | JSON設定、保存先、形式、テーマ、自動コピー/保存、JPEG画質、ホットキー、起動時動作の読み書き |
| ライト/ダークテーマ | UI | 1 | 設定画面からSystem/Light/Darkを切替・保存できる |
| メイン画面/ナビゲーション | 基盤 | 1 | Capture/OCR/QR/History/Settingsへ遷移し、未実装機能を明示 |
| ログ | 基盤 | 1 | 起動/終了、設定読込/保存、例外をconsoleとローカルファイルに記録 |
| DI/Platform contracts | 基盤 | 1 | 必須7 interfaceを登録し、未実装呼び出しは明確な例外を返す |
| macOS GUI起動 | 基盤 | 1 | arm64 self-contained `.app`からウィンドウを表示 |

## OS別実装

| サービス | macOS | Windows 11 |
|---|---|---|
| 撮影 | ScreenCaptureKit | Windows.Graphics.Capture |
| OCR | Apple Vision | Windows.Media.Ocr（MSIX package identity制約を考慮） |
| QR/バーコード | 共通ZXing.Net | 共通ZXing.Net |
| 画像処理 | 共通SkiaSharp | 共通SkiaSharp |
| UI/MVVM | 共通Avalonia | 共通Avalonia |
| クリップボード/ホットキー/スクロール制御 | 共通契約+OS実装 | 共通契約+OS実装 |

各機能は実機または適切な自動テストで検証されるまで「完了」としない。Phase 1ではUIの項目/ナビゲーションと設定基盤までを実装し、撮影・画像処理・OCR機能はまだ存在しない。
