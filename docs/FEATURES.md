## OS別実装

| サービス | macOS | Windows 11 |
|---|---|---|
| 撮影 | ScreenCaptureKit | Windows.Graphics.Capture |
| OCR | Apple Vision | Windows.Media.Ocr（MSIX package identity制約を考慮） |
| QR/バーコード | 共通ZXing.Net | 共通ZXing.Net |
| 画像処理 | 共通SkiaSharp | 共通SkiaSharp |
| UI/MVVM | 共通Avalonia | 共通Avalonia |
| クリップボード/ホットキー/スクロール制御 | 共通契約+OS実装 | 共通契約+OS実装 |

各機能は実機または適切な自動テストで検証されるまで「完了」としない。今回の画像処理実装はcrop、PNG/JPEG encode/decode、ファイルI/Oに限る。OCR、QR、編集機能はまだ存在しない。
